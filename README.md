# Nexus

A modern TikTok-style web application featuring video feeds, user profiles, authentication, and a responsive design.

## Features
- **Video Feed**: Scrollable "For You" and "Following" video feeds.
- **Authentication**: Custom authentication integrated with Supabase.
- **User Profiles**: Manage your profile, view your videos, and delete content.
- **Interactions**: Like, comment, and follow users.
- **Responsive Design**: Works on Desktop and Mobile with an app-like bottom navigation.

## Technologies Used
- HTML, CSS, JavaScript (Vanilla SPA)
- Supabase (PostgreSQL, Auth, Storage)
- Vercel (Hosting)
